# Native text comparison rubric A01

Parent and judge score each complete candidate from 0 to 5 on each criterion.

1. Caller depth and ordering: one existing Project workflow; one z-order; font import without timed-stream fiction; no native objects or shaping stages in public usage.
2. Identity and typography: exact font-byte/face/table identity; UTF-8/UTF-16 and run coverage; fallback/missing glyph rejection; explicit language/direction/backend/raster evidence.
3. Geometry and ownership: one exact coordinate and rounding contract; no unproved glyph clipping; admitted application-owned allocations; bounded worker cache and cancellation.
4. Compatibility and integration: exact absent-field legacy bytes; Plan7 preservation; complete new-plan admission across prepare/replay/render/verify/recovery; no output-profile renumbering.
5. Verifiability and extension: selected API feasibility probe; independent actual Indic shaping/raster proof; exact pure vectors; plan tamper controls; ordinary native output and lifecycle evidence.

Any unresolved fallback authority, unproved layout clipping, native-object channel transfer, or legacy-byte break is a blocker regardless of score.
Prefer the smaller caller surface and a complete practical proof path when scores tie.
