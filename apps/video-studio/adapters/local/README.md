# Local observer diagnostic

`audio_observer.py` accepts an exact WAV sample range and observes it through the installed local Qwen audio model.
The worker reserves the shared GPU inside a genuine Herdr pane.
It verifies canonical source bytes, pinned model shards, preprocessing extent and actual attended audio features.
It retains the raw model response and every technical binding.

This adapter runs separately from the Rust editor and has no renderer role.
It cannot establish full normal-speed playback, human listening or creative acceptance.
No old application runtime is imported.
The model interface was checked against the [publisher model card](https://huggingface.co/Qwen/Qwen2-Audio-7B-Instruct) and [Transformers documentation](https://huggingface.co/docs/transformers/model_doc/qwen2_audio).
Tenant authorization and persistent job orchestration remain separate implementation work.
